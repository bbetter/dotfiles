# Hyprland config (native Lua)

- Hyprland 0.56 loads `hyprland.lua` directly. There is **no** `hyprland.conf`.
  `hyprland.lua` `dofile()`s `env`, `autostart`, `monitors`, `workspaces`, `look`,
  `plugins`, `input`, `windows`, `binds` (in that order).
- API is `hl.*`: `hl.config{}`, `hl.bind`, `hl.dsp.*`, `hl.animation{}`, `hl.curve`,
  `hl.window_rule`, `hl.layer_rule`, `hl.workspace_rule`, `hl.env`, `hl.on(...)`.
- Apply changes with `hyprctl reload`, then check `hyprctl configerrors` (empty = OK).
  Verify options with `hyprctl getoption <section:name>`.
- From a shell, use the Lua form: `hyprctl dispatch 'hl.dsp.focus({ workspace = 1 })'`.
  Legacy syntax such as `exec [rules] cmd` is a Lua syntax error.
- `~/.config/theme/hyprland-colors.lua` is generated by the wallpaper theme pipeline
  and `dofile`d last by `look.lua`. It is git-ignored; edit the `.template.lua`, not the output.
- This directory is a stow package in `~/.dotfiles` (edits via `~/.config/hypr` land in
  the repo). A nightly timer auto-commits the working tree.
- `hyprlock.conf` is rendered from `hyprlock.template.conf`; edit the template.
- 165Hz / HDR history, rollback tags and `./fallback.sh <tag>`: see `HDR-NOTES.md`.
